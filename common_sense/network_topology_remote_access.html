网络连接与远程访问拓扑

最后更新：2026-06-13。当前文档按 WALLE 机器人平台入口和反向 SSH 隧道现状修订。

一句话结论

公网业务走 WALLE 网关，树莓派运维走腾讯云反向 SSH 隧道。

外网访问机器人业务时，优先走 https://www.wangyutang.cn/。 远程登录树莓派时，Windows 先连腾讯云 110.40.154.41，再通过腾讯云本机 127.0.0.1:10022 转进树莓派 SSH。当前检查结果是：腾讯云端口仍在监听，但 SSH banner 超时，需在树莓派侧排查 reverse-ssh-tencent.service。

推荐登录方式

方式一：使用本机 SSH alias

这是最推荐的方式，配置集中在 Windows 的 C:\Users\Administrator\.ssh\config。

ssh raspberrypi-via-tencent

方式二：一条命令显式跳板登录

ssh -o HostKeyAlias=raspberrypi-via-tencent -J tencent -p 10022 pi@127.0.0.1

方式三：两步登录

ssh tencent
ssh -p 10022 pi@127.0.0.1

方式四：同一局域网内直连

ssh pi@raspberrypi.local
ssh pi@树莓派局域网IP

当前需要注意的状态

  • 腾讯云上 127.0.0.1:10022 仍有 sshd 监听，说明反向隧道端口存在。
  • 但从腾讯云本机登录 ssh -p 10022 pi@127.0.0.1 当前出现 banner 超时，不能直接视为端到端可用。
  • 优先到树莓派本机排查 reverse-ssh-tencent.service、网络在线状态、SSH server 状态和隧道私钥权限。
  • 业务访问不依赖树莓派 SSH 隧道；公网业务当前由 robot-gateway 转发到 Docker 内部服务。

安全边界

  • 腾讯云公网 22 端口是腾讯云自己的 SSH，不是树莓派。
  • 树莓派 SSH 隧道只监听腾讯云本机 127.0.0.1:10022，不要直接暴露到公网。
  • 树莓派密码和 Wi-Fi 密码不写入本文档，需要时由 owner 临时提供。
  • 如果要公开暴露 10022，必须额外评估安全组、强密码、密钥登录和审计策略；当前不建议。
