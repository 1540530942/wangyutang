最常用登录指令

同一个局域网内

ssh pi@192.168.1.46

也可以使用主机名：

ssh pi@raspberrypi.local

不在局域网内，走腾讯云反向隧道

两步登录：

ssh tencent
ssh -p 10022 pi@127.0.0.1

一条命令直达：

ssh -o HostKeyAlias=raspberrypi-via-tencent -J tencent -p 10022 pi@127.0.0.1

反向 SSH 隧道

树莓派上已配置常驻服务：

/etc/systemd/system/reverse-ssh-tencent.service

核心转发关系：

腾讯云 127.0.0.1:10022  ->  树莓派 localhost:22

树莓派服务中的核心命令：

/usr/bin/ssh -N -T \
  -i /home/pi/.ssh/id_ed25519_tencent_tunnel \
  -o ExitOnForwardFailure=yes \
  -o ServerAliveInterval=30 \
  -o ServerAliveCountMax=3 \
  -o StrictHostKeyChecking=yes \
  -R 127.0.0.1:10022:localhost:22 \
  root@110.40.154.41

已验证状态：

reverse-ssh-tencent.service: active
Tencent Cloud listening: 127.0.0.1:10022
remote login result: hostname=raspberrypi, user=pi

不在局域网时如何登录树莓派

方式一：两步登录

ssh tencent
ssh -p 10022 pi@127.0.0.1

方式二：一条命令跳板登录

ssh -o HostKeyAlias=raspberrypi-via-tencent -J tencent -p 10022 pi@127.0.0.1

第二种方式会从 Windows 先连腾讯云，再通过腾讯云本机的 127.0.0.1:10022 转进树莓派。

在局域网内如何登录树莓派

如果 Windows 和树莓派同在 192.168.1.0/24，可以直连：

ssh pi@192.168.1.46
ssh pi@raspberrypi.local

当前已验证局域网直连成功：

安全边界

  • 腾讯云公网 22 端口是腾讯云自己的 SSH，不是树莓派。
  • 树莓派 SSH 隧道只监听腾讯云本机 127.0.0.1:10022，没有直接暴露到公网。
  • 树莓派密码和 Wi-Fi 密码不写入本文档；需要时由 owner 临时提供。
  • 如果要公开暴露 10022，需要额外评估安全组、密码强度和密钥登录策略；当前不建议。
