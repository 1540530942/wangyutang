web模式（浏览器麦克风 / 扬声器）

点击「开始对话」后，浏览器持续采集麦克风并发送到云端；audio_interact 用 Silero VAD 自动断句，每句 ASR→唤醒词判断→robot_sandbox 指令→安全→真实执行，TTS 由浏览器扬声器自动播报。 需说唤醒词（如“你好瓦力”）才会触发动作。也可直接上传一段音频识别。
