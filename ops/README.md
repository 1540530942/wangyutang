# 运维配置示例

本目录中的文件是需要人工审查和安装的示例，不是仓库部署流程的一部分。克隆、拉取或推送仓库不会让任何设备自动应用这些配置。

安装前：

1. 阅读 [`../docs/ops/README.md`](../docs/ops/README.md)；
2. 选择目标设备对应的文件；
3. 复制到系统目录后替换全部 `REPLACE_...`，并确认示例端口 `22022`、`22023`、`22024`；
4. 验证 hub 主机密钥、端口唯一性、用户、密钥路径和文件权限；
5. 保留独立访问路径和可自动执行的回滚；
6. 通过语法检查后才启用或 reload。

任何 `.example` 文件都不应未经编辑直接安装到生产系统。

`ssh/check-reverse-tunnels.sh` 是只读诊断脚本，可以直接运行；参数必须显式给出为 `别名:端口`。它不会 reload、restart、kill 或修改配置。
